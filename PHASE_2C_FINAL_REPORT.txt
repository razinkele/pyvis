## What Was Implemented

### The Change
Modified `add_node()` in pyvis/network.py to raise `ValueError` when attempting to add a node with a duplicate ID.

**Before:**
```
Warning: Node 1 already exists and was not updated. Use update_node() to modify existing nodes.
```

**After:**
```
ValueError: Node 1 already exists in the network. Use update_node() to modify existing nodes, 
or remove the duplicate add_node() call.
```

### Why This Matters

1. **Catches Bugs Earlier**: Explicit errors instead of silent warnings
2. **Better Debugging**: Stack trace shows exact location of duplicate call
3. **Clearer API**: Obvious failure mode, not a silent no-op
4. **Consistent**: Matches expected behavior of other network operations
5. **Safer Defaults**: Fail fast, not silently

## Implementation Details

### Files Modified
1. **pyvis/network.py** - add_node() method (lines 615-620, +3 for docstring)
2. **pyvis/tests/test_network_basic.py** - test_add_node_duplicate_raises() (updated)
3. **pyvis/tests/test_graph.py** - test_no_dup_nodes() (updated)

### Code Change
```python
# OLD CODE:
warnings.warn(
    f"Node {n_id!r} already exists and was not updated. "
    f"Use update_node() to modify existing nodes.",
    UserWarning, stacklevel=2
)

# NEW CODE:
raise ValueError(
    f"Node {n_id!r} already exists in the network. "
    f"Use update_node() to modify existing nodes, or remove the duplicate add_node() call."
)
```

### Documentation Added
```python
:raises TypeError: If n_id is not a string or integer.
:raises ValueError: If a node with the same n_id already exists in the network.
                    Use update_node() to modify existing nodes.
```

## Breaking Change Management

### What's Breaking
- Code that adds duplicate nodes expecting silent warning
- Will now raise ValueError instead

### Who's Affected
- Users with code that adds duplicate nodes accidentally
- Users relying on silent ignoring behavior (rare)

### Migration Path (3 Options)

**Option 1: Use update_node()** (Recommended)
```python
net.add_node(1, label="First")
net.update_node(1, label="Second")  # ✅ Best practice
```

**Option 2: Check before adding**
```python
if node_id not in [n["id"] for n in net.nodes]:
    net.add_node(node_id, label="Label")
```

**Option 3: Error handling**
```python
try:
    net.add_node(1, label="Node")
except ValueError:
    net.update_node(1, label="Node")
```

### Effort to Migrate
- ⏱️ **Low** - Most code unaffected
- ⏱️ Most duplicates are accidental bugs anyway
- ⏱️ Simple fix when encountered
