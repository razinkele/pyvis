============
Installation
============

----------------
Install with pip
----------------

.. code-block:: bash

    $ pip install pyvis-optimized

The import name is unchanged (``from pyvis.network import Network``). Optional
extras: ``pyvis-optimized[shiny]``, ``pyvis-optimized[notebook]``.

Or you can download an archive of the project here_. To install, unpack it 
and run the following in the top-level directory:

.. code-block:: bash

    $ pip install .

.. _here: https://github.com/razinkele/pyvis
