## BEHAVIOR CHANGES

### Before (Old Behavior)
```python
from pyvis.network import Network

net = Network()
net.add_node(1, label="First")
net.add_node(1, label="Second")

# Result: UserWarning issued, node unchanged (silent failure)
# Label remains: "First"
```

### After (New Behavior)
```python
from pyvis.network import Network

net = Network()
net.add_node(1, label="First")
net.add_node(1, label="Second")

# Result: ValueError raised
# Traceback shows exact line where duplicate occurred
# Fails fast with clear error message
```

### Migration Path

**Option 1: Use update_node() for modifications**
```python
net.add_node(1, label="First")
net.update_node(1, label="Second")  # ✅ Correct way
```

**Option 2: Check before adding**
```python
if node_id not in [n["id"] for n in net.nodes]:
    net.add_node(node_id, label="Label")
```

**Option 3: Error handling**
```python
try:
    net.add_node(1, label="Node")
except ValueError:
    net.update_node(1, label="Node")
```
