### Breaking Change Documentation

**Old Behavior:**
```python
net.add_node(1)
net.add_node(1)  # Silent warning, node unchanged
```

**New Behavior:**
```python
net.add_node(1)
net.add_node(1)  # Raises ValueError
```

**Migration Path:**
1. Use update_node() to modify existing nodes
2. Check node existence before adding
3. Wrap in try-except if conditional handling needed
