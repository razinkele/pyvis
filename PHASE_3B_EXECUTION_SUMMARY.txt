Implement ARCH-002: Add helper methods for common graph query operations to the PyVis Network class.

## 📝 What Was Done

### 1. Implementation (pyvis/network.py)
- **get_node_ids()** - Returns all node IDs in the network
- **get_edge_ids()** - Returns all edges as (source, dest) tuples
- **get_neighbors(node_id)** - Returns adjacent nodes for a given node
- **get_node_degree(node_id)** - Returns the degree (edge count) of a node
- **has_edge(source, dest)** - O(1) check if an edge exists
